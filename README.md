# 📚 Library Management System

## 📌 Project Description

The **Library Management System** is a simple Java-based console application designed to manage basic library book information.

This project allows users to add a book, view book details, and search for a book using its Book ID. Other library management features are included in the menu and can be implemented in the future.

## 🛠️ Technologies Used

* **Java**
* **Java Scanner Class**
* **Object-Oriented Programming (OOP) Concepts**
* **Console/Command Line Interface**

## ✨ Features

1. **Add Book**

   * Enter Book ID
   * Enter Book Name
   * Enter Book Author
   * Enter Book Category
   * Enter Total Copies

2. **View Book**

   * Displays complete details of the added book.

3. **Search Book**

   * Searches for a book using its Book ID.

4. **Issue Book**

   * Currently shows "Coming Soon".

5. **Return Book**

   * Currently shows "Coming Soon".

6. **Delete Book**

   * Currently shows "Coming Soon".

7. **Library Report**

   * Currently shows "Coming Soon".

8. **Exit**

   * Exits the Library Management System.
